端口转发

正向（本地 → 远端）：在你本机开一个端口，流量经 SSH 送到跳板机侧的目标。等价命令 ssh -L 20000:127.0.0.1:3306 user@跳板机。
例：远端目标填 127.0.0.1 + 3306（MySQL）→ 本机用 localhost:20000 就连到了它；本地端口从 20000-20010 自动分配，Docker 已映射。

反向（远端 → 本机）：在跳板机上开一个端口，流量经 SSH 回到你本机正在跑的服务。等价命令 ssh -R 8080:127.0.0.1:3000 user@跳板机。
例：远端监听 8080、本机目标 127.0.0.1:3000 → 在跳板机上访问 localhost:8080 就到你本机的 3000 端口。

反向需远端 sshd 开启 AllowTcpForwarding；要让跳板机以外的机器也能访问，还需 GatewayPorts yes，并把远端监听地址填 0.0.0.0。
